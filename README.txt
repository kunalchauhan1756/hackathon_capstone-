## Project Description
This project manages online competitions and hackathons for an organizing institution. It handles participant registration, team formation, problem statements, project submissions, judges, scoring criteria, automatic ranking, and result reports.

## Files Included
1. DBMS Project Report
2. ER Diagram
3. Database Schema and Sample Data SQL File
4. SQL Queries and Testing SQL File
5. Output Screenshots

## Instructions to Run
1. Open MySQL Workbench.
2. Execute hackathon_schema_data.sql first.
3. Execute hackathon_queries.sql after successful database creation.
4. Review the generated reports, score sheets and leaderboard.

## PDF VS Code mein kaise dekhein
VS Code PDF ko by default text/binary dikhata hai. Isliye:
1. Folder VS Code mein kholo -> neeche popup aayega "Install recommended extension" -> "vscode-pdf" (tomoki1207) install karo.
   Ya Extensions (Ctrl+Shift+X) mein "vscode-pdf" search karke install karo.
2. Install ke baad PDF file par click karo, ab proper PDF viewer mein khulegi.
3. Extension na chahiye to PDF_Pages/ folder mein har PDF ke pages PNG images ke roop mein hain,
   jo VS Code mein seedha khulte hain.
